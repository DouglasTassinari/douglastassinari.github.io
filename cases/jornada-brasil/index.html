Ferramentas que nasceram de problemas de gente próxima — e viraram um site público

O jornadabrasil.com.br ↗ reúne 16 ferramentas e 37 artigos para quem transita entre CLT e trabalho autônomo. Cada ferramenta começou resolvendo o problema de alguém que eu conhecia; o site existe para que qualquer pessoa tenha a mesma resposta.

Desafio
Dúvidas que a internet respondia pela metade ou com regra desatualizada: quanto vou receber, quanto cobrar por um serviço, quanto sobra do que eu faturo.
O que fiz
Levei soluções feitas para pessoas próximas a um site público, com artigos explicativos e tudo num único domínio.
Resultado
A calculadora de imposto de renda passou de 100 acessos por mês vindos do Google em dois meses; o site recebe cerca de 130 usuários por mês.
Meu papel
Tudo — produto, código, conteúdo, SEO e operação —, fora do horário de trabalho.

De onde veio cada ferramenta

  1. Colegas

    Quanto eu vou receber?

    Uma planilha de previsão salarial, montada com as regras certas para colegas de trabalho, virou a calculadora de salário líquido e as de direitos trabalhistas.

  2. Meu pai

    Quanto eu cobro?

    Ele não conseguia orçar um serviço de cabeça. A ferramenta que fiz para ele virou o precificador para autônomos.

  3. Meu irmão

    Quanto eu ganhei de verdade?

    Motorista de aplicativo, ele achava que faturar 200 era ganhar 200. A ferramenta que separa faturamento de lucro virou o Meu Lucro.

Duas decisões que pesaram

Unificar na superfície, não reescrever

As ferramentas nasceram como produtos separados. Foram costuradas num único domínio — navegação, identidade e medição de acesso — preservando todos os endereços que o Google já conhecia.

Alternativa rejeitada — Migrar tudo para um framework. Ganharia elegância de código e perderia o posicionamento orgânico acumulado; o SEO era o ativo, e a migração se desenhou ao redor dele.

O dado do usuário fica no navegador

As ferramentas funcionam sem cadastro: salário e faturamento digitados ficam no próprio navegador, e a conta de usuário é opcional.

Alternativa rejeitada — Exigir conta desde o início. Criaria atrito antes de entregar valor e transformaria cada salário digitado em responsabilidade de LGPD.

Detalhes técnicosStack, operação e consolidação dos repositórios

Stack

  • HTML, CSS e JavaScript
  • React via CDN
  • PWA
  • Supabase (conta opcional)
  • GitHub Pages
  • GitHub Actions
  • GA4 + Consent Mode
  • AdSense

Outras decisões

  • Consolidação com histórico — os repositórios viraram um só por git subtree, e os endereços antigos redirecionam com canonical para não perder indexação.
  • Uma camada compartilhada — identidade visual, navegação, consentimento e armazenamento escritos uma vez e usados por todas as ferramentas.
  • Monitoração sem serviço pago — uma rotina no GitHub Actions verifica a disponibilidade do site a cada 15 minutos.

Aprendizados

  1. Uma pessoa real com um problema real é o melhor ponto de partida. Quando a ferramenta resolve de verdade para alguém próximo, resolve para muita gente com a mesma dúvida.
  2. SEO construído é ativo de engenharia. A decisão mais importante do projeto foi a que ninguém vê: desenhar a consolidação em volta dos endereços indexados, e não do código.
